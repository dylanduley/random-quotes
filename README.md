# random-quotes

A small page of quotes I like, for good reminders. Click the dice (or press space) for a random one.

## Adding quotes

Add a line to `quotes.js`:

```js
{ text: "The quote.", author: "Who said it" },
```

`author` is optional. Use `\n` in `text` for a line break.

## Running it

Open `index.html` in a browser, or host it with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).
